# BITNET — Microsoft 1.58-bit (ternary) LLM evaluation (domain SSOT)

@goal: Empirically characterize Microsoft BitNet b1.58 (1.58-bit ternary-weight LLM) on the self-hosted SANDBOX substrate — accuracy / memory / latency vs full-precision baselines — and confirm-or-refute the atlas BT-77 quantization claim by recompute.

> Rides on the SANDBOX measurement substrate (sibling domain). Seed: atlas `BT-77`
> ("BitNet Quantization n=6 — 2B4T 25/26 EXACT, 3 models × 2 teams, 40/41 total", `[10*]`).
> BitNet b1.58 = weights ∈ {-1, 0, +1} (~1.58 bits/weight); claims near-fp16 quality at a
> fraction of memory/energy. Runnable via `bitnet.cpp` / `llama.cpp` GGUF (BitNet b1.58 2B4T).

- [x] M5 Verdict — atlas BT-77 (2B4T 25/26 EXACT) **CONFIRMED by recompute** on our substrate. **결정적 발견: BT-77의 "25/26 EXACT"는 served-accuracy 벤치마크가 아니다** (M1/M2의 정확도 floor와는 완전히 별개 축) — n=6 **numerology** 주장이다. witness(`hexa-chip/AI-EFFICIENCY.md` §`bt77-bitnet-quantization-n6.md`, 3-star p<1e-15)는 BitNet b1.58 2B4T의 config 하이퍼파라미터 26개가 각각 n=6 약수 상수 `{n=6, σ=12, φ=2, τ=4, sopfr=5, J2=24, μ=1}`로 만든 closed-form 식과 EXACT 일치한다고 주장(예: d_model 2560 = 2^(σ-τ)·(σ-φ), n_layers 30 = sopfr·n, d_ffn 6912 = 2^(σ-τ)·(n/φ)^(n/φ) = 2^8·3^3, vocab 128256 = 2^(σ-sopfr)·10^(n/φ)+2^(σ-τ)). "26"의 denominator는 1개 non-EXACT = 71.4× 에너지비(σ·n=72에 CLOSE, 0.8% 이내)를 포함 → 25 EXACT + 1 CLOSE. "40/41 total"은 1bitLLM 팀의 700M(6/6)·3B(6/6) 형제 모델 합산. **이건 결정적·closed-form이라 우리 substrate에서 $0·GPU 불필요로 재계산 가능 — citation-only가 아니다.** 재계산: `bench/bitnet_m5_bt77_recompute.hexa`가 (a) 모든 n=6 식을 hexa-native 정수/유리수 산술로 평가해 witness 값과 일치 확인, (b) config.json에 있는 아키텍처 파라미터(d_model·n_layers·n_heads·n_kv_heads·d_ffn·max_pos·rope_theta·vocab 등)는 **로컬 실제 `microsoft/bitnet-b1.58-2B-4T-bf16/config.json`**(M1에서 받아둔 것)과 교차검증. **결과: 2B4T witness-aligned 25/26 EXACT + 1 CLOSE — 등록 주장과 정확히 일치, FAIL 0개.** 전체 3개 모델 raw 38/40 EXACT(+1 CLOSE). 식 하나도, 실제 config 값 하나도 어긋나지 않음. 기반 n=6 상수는 `hexa verify --expr {sigma,phi,tau,mu}(6)` → 🔵 SUPPORTED-FORMAL로 별도 확인. **tier = 🟢 SUPPORTED-NUMERICAL (recompute confirms)** — atlas가 등록한 citation tier보다 강함. **정직한 confound:** 재계산이 확인하는 것은 (i) witness 산술이 내부적으로 일관되고 (ii) 아키텍처 값이 실제 출하 config와 일치한다는 것뿐 — n=6-표현가능성이 **인과적**인지 vs 유연한 7-상수 basis(±×÷^, ~3항, [1,10000]에서 ~5% 임의-적중률)의 **artifact**인지는 재계산이 판가름할 수 없는 별개의 significance 질문이다(재계산 불가; M6 seed = random-config null model로 정량화). `.verdicts/bitnet/m5_bt77_recompute.txt` + `.tsv` · `.discoveries/bitnet-m5-bt77-numerology-recompute.tape`.
