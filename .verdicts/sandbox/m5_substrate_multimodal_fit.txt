# ── PART 4 — CLOSED-FORM FIT + HONEST-NEGATIVE VERDICT ──────────────
# HONEST-NEGATIVE on overall monotonicity (a CLOSED/valid outcome per the milestone):
# overall accuracy is NON-MONOTONE in params (rise-then-fall), so a single logistic in
# log2(params) — monotone by construction — is the WRONG functional family for the
# overall curve (best monotone-logistic RMSE = 0.056, a structural misfit it cannot
# bend down to remove). This is NOT a quantization artifact: a separate Q8_0 Qwen-VL-3B
# probe counts the dense 5–9-object images identically to the committed Q4_K_M rung
# (5,6,6,7,8 vs gold 5,6,7,8,9), so the 3B rung GENUINELY undercounts where the 2.2B
# rung does not.
#
# The gradient SPLITS by axis (recomputed from the committed TSV):
#   PERCEPTION sub-ladder (ocr + spatial + shape, 11 items) IS monotone-non-decreasing
#     then SATURATES: 0.5B 9/11 (81.8%) → 2.2B 11/11 (100%) → 3.0B 11/11 (100%).
#     ← the real, defensible capability gradient once the params-orthogonal counting
#       axis is separated.
#   COUNTING axis (5–9 dense objects, 5 items) does NOT track params — a known VLM
#     subitizing-limit weakness (0.5B 4/5, 2.2B 4/5, 3.0B 2/5) that breaks the overall
#     monotone trend.

#   non-monotone on the overall harder manifest, monotone-then-saturating on perception.
