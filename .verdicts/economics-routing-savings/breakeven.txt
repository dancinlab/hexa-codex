==============================================================================
  HEADLINE
==============================================================================

  • Dominant variable is p_opus, NOT p_haiku.
    In the observed N=200 data, haiku and sonnet tiers cost nearly the same
    per task (~$0.0033) because output-token volume on short trivial answers
    dwarfs the per-token-rate difference between models.
  • Routing buys ~79% saving at p_opus=0, ~−0.4% at p_opus=1 (noise: router
    and baseline both dispatch opus on opus-class prompts).
  • Linear approximation: saving% ≈ 79.2 − 79.6 · p_opus  (within ±1pp across
    the haiku/sonnet split at fixed p_opus).

==============================================================================
  CAVEATS — strong assumptions baked into the model
==============================================================================

  (A) Tier-monotone cost assumption: model assumes a given prompt would cost
      less on haiku than on sonnet than on opus. This is FALSE in places.
      The 2-tier ablation (.verdicts/economics-routing-savings/2tier.tsv) showed
      cases where haiku actually costs MORE than sonnet on the same prompt —
      haiku tends to produce longer answers (and pays per-output-token).
  (B) Per-prompt cost depends on OUTPUT length, which is itself model- and
      prompt-dependent. We use empirical mean per-task cost as a proxy, which
      collapses that variance. The sweep therefore predicts CENTRAL TENDENCY,
      not worst-case.
  (C) The N=20 manifest is essentially all-sonnet by length cutoff (19/20),
      so its 70.4% (originally reported 73.56% — minor rounding due to a
      different aggregation path in summary) saving sits on the high-p_haiku
      end of the curve. Real production manifests with non-trivial p_opus
      will see lower saving and may cross below 30% when p_opus > ~0.57.
  (D) Cost data from the Anthropic --output-format json `total_cost_usd` field
      via the `claude` CLI; cache-token contributions blur some per-task
      figures (note router task 2 at $0.00272 had 1962 input_tokens recorded —
      a cache-prefix accounting artifact). Aggregate totals are still valid.
  (E) Per-tier baseline cost ($0.01535 haiku-class vs $0.01925 opus-class)
      shows opus is ~25% more expensive on harder prompts even at the SAME
      model — output-token volume scales with prompt difficulty.
